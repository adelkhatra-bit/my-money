# 🎨 Icônes Extension

## Fichiers disponibles

- `icon.svg` - Icône vectorielle (source)
- `generate-icons.html` - Générateur d'icônes PNG
- `CREATE_ICONS.md` - Instructions complètes

## Option 1 : Utiliser generate-icons.html (RECOMMANDÉ)

1. Ouvrir `generate-icons.html` dans Chrome
2. Cliquer sur "Download All Icons"
3. Les 3 fichiers PNG sont téléchargés :
   - `icon16.png`
   - `icon48.png`
   - `icon128.png`

## Option 2 : Utiliser icon.svg

Si tu as un outil de conversion SVG → PNG (Inkscape, GIMP, etc.) :

1. Ouvrir `icon.svg`
2. Exporter en PNG aux tailles :
   - 16×16 → `icon16.png`
   - 48×48 → `icon48.png`
   - 128×128 → `icon128.png`

## Option 3 : Utiliser l'extension sans icônes

L'extension fonctionnera même sans icônes personnalisées.
Chrome affichera simplement une icône par défaut.

## Design de l'icône

**Couleurs :**
- Fond : Dégradé bleu (#3b82f6 → #2563eb)
- Robot : Blanc (#ffffff)

**Éléments :**
- Tête de robot (carré avec bordure)
- Deux yeux (carrés)
- Bouche (rectangle)
- Antenne (en haut)

**Style :**
- Minimaliste
- Flat design
- Coins arrondis (24px)
