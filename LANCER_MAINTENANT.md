## 🎯 ÉTAPES POUR VOIR LE SITE

### OPTION 1 : Ouvrir en nouvel onglet (PRIORITAIRE)

1. Dans Bolt, trouvez le preview (iframe blanc)
2. Cherchez l'icône **↗️ "Open in new tab"** en haut à droite du preview
3. Cliquez dessus
4. Faites **Ctrl+Shift+R** (hard refresh)

➡️ **Si ça marche** : le site s'affiche dans le nouvel onglet

---

### OPTION 2 : Accéder directement au serveur local

1. Ouvrez votre navigateur
2. Allez sur : `http://localhost:3000` ou `http://192.168.1.104:3000`
3. Faites **Ctrl+Shift+R**

➡️ **Si ça marche** : le site s'affiche

---

### OPTION 3 : Redémarrer le serveur

Si les options 1 et 2 ne marchent pas:

```bash
# Arrêter le serveur (Ctrl+C dans le terminal)
# Puis relancer:
npm start
```

Attendez "Compiled successfully", puis retentez OPTION 1 ou 2.

---

## 🔍 SI TOUJOURS BLANC → DIAGNOSTIC

1. Ouvrez DevTools (**F12**)
2. Allez dans l'onglet **Console** (pas Issues)
3. Cherchez une ligne **rouge** (Error)
4. Copiez l'erreur complète

**Avec l'erreur Console, on peut corriger en 2 minutes.**
